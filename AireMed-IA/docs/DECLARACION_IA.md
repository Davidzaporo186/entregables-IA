# Declaración de uso de IA generativa (validar antes del envío)

Se utilizó **ChatGPT (OpenAI)** como herramienta de apoyo en la propuesta de arquitectura, redacción del código Python y Streamlit, documentación, generación de pruebas y revisión de consistencia. El equipo debe revisar, ejecutar, comprender y adaptar el código y validar los resultados de sus propias pruebas antes de presentarlo como trabajo propio.

La aplicación integra opcionalmente un modelo LLM de **Groq** mediante API compatible con OpenAI. Para ejecutar ese agente se utiliza una clave privada de cada usuario; el proyecto no incluye claves ni resultados atribuidos a una API sin haberla ejecutado.

Los datos provienen de SIATA (enero de 2025); las interpretaciones quedan limitadas a estadísticas mensuales. No se usan datos personales.

**Equipo:** completar nombres, identificación, aportes individuales y declaración del uso realmente realizado. La revisión final, autoría responsable y envío corresponden a los integrantes.
